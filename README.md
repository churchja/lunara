# LUNARA-P sky page

The public copy of the LUNARA-P moon lamp's page, for phones and computers that are not on the lamp's network.

- `sky/index.html` is the page. It is built by the lamp project's page builder (`build_page.py --public`) and copied here unchanged. Do not edit it by hand; rebuild and copy.
- `index.html` sends visitors on to `sky/`. It is a placeholder for a product home page.

The page runs as a demo: it has no lamp to talk to, so the Lamp tab changes nothing. The Moon tab's "Your sky"
view works from the visitor's own clock and place, and on a phone the Compass button turns the sky with the phone.
